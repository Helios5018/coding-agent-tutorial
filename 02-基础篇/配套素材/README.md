# 配套素材说明

这是《基础篇：从零开始使用 Coding Agent》第四章「上手三个真实任务」的练习素材。

## 里面有什么
- `会议材料/`：一个虚构「晨读 App」产品团队 2026 年 3 月的一堆原始文件——会议纪要、周报、复盘、决策记录、KPI 表格。
- 这些文件是**故意弄乱的**：命名五花八门、格式有 md / txt / csv / Word，乱放在一个文件夹里。这正是任务 A 要你和 Agent 一起收拾的对象。

## 怎么用
1. **先复制一份再动手。** 把整个 `配套素材/` 文件夹复制一份（比如改名 `配套素材-练习`），在副本上操作。原件留着，搞砸了随时能重来。
2. 用 Codex App（或你顺手的工具）打开复制出来的文件夹，跟着正文第四章的任务 A → B → C 一步步做。
3. 三个任务是连着的：A 把文件整理好 → B 让 Agent 把它们总结成一份文档 → C 基于这些内容做一个能跑起来的可视化网页。

这里只给原始素材，不给"标准答案"——自己跑一遍，才学得会。卡住了就回正文对应章节看思路。
